# Training data files

| File | Type | Use |
|------|------|-----|
| `plots_training_seed.csv` | **Synthetic** (`dataSource=synthetic`, `seed_proj_*`) | Local/dev bootstrap only |
| `plots_production_export.csv` | **Real** (`dataSource=mongodb_export`) | Generated by `python export_plots_csv.py` |

## Production workflow (for TL / deploy)

```powershell
cd analytics
python export_plots_csv.py
# .env: TRAINING_USE_SEED_CSV=false
python train.py --mongo-only
# or merge export + mongo:
# TRAINING_CSV=./data/plots_production_export.csv python train.py --no-seed
```

**Rule:** Production training must use **Mongo sold plots** and/or **exported CSV from Mongo**. Do not rely on `plots_training_seed.csv` in production (`TRAINING_USE_SEED_CSV=false`).

## CSV schema (matches `plot.model.js`)

Required: `projectid`, `plotnumber`, `plotsize`, `roadWidthFt`, `plotType`, `approvalStatus`, `plotdirection`, `plotprice`, `plotstatus`

Optional: `createdAt` (ISO UTC), `dataSource` (`mongodb_export` | `synthetic` | `manual`)

`plotstatus`: **Available** | **Sold** | **Reserved** (Reserved — not "booked")
